## Grok 是什么？

Grok 是马斯克旗下 xAI 公司（已并入 SpaceXAI）开发的 AI 助手，深度集成 X（原 Twitter）平台，
能够实时获取 X 上的最新信息，风格幽默犀利，是目前少数能够访问实时网络数据的 AI 产品之一。
当前最新旗舰为 **Grok 4.7**（2026年9月21日发布），支持 Expert 推理模式、视频生成、AI 语音伴侣及 500K tokens 超长上下文，在 Grok Build、Cursor 和 API 全面可用。Grok 4.6（2026年8月12日）为上一代旗舰。

---

## 注册前的准备

- **稳定的网络环境**：需要全程保持连接，建议使用美国节点
- **账号选择**：可使用 X 账号登录，也可直接在 grok.com 注册独立账号
- **海外邮箱**：注册时使用 Gmail 或 Outlook

## 详细注册步骤

### 第一步：选择访问入口

Grok 目前有两个访问入口：

- **独立网站**：打开 [grok.com](https://grok.com)，无需 X 账号即可注册使用
- **X 平台内**：登录 X 后，点击左侧菜单「Grok」图标直接进入

> 📌 grok.com 支持独立注册，不强制要求绑定 X 账号。

### 第二步：注册或登录

在 grok.com 点击「Sign up」，用海外邮箱注册，或选择「Sign in with X」用现有 X 账号授权登录。

### 第三步：完成验证

按提示完成邮箱验证，若通过 X 账号登录则授权后直接进入主界面。

### 第四步：开始使用

注册完成，免费版即可使用 Grok 的基础额度，每2小时约10条消息。

## Grok 的核心优势

**实时信息**：深度整合 X 平台数据，能获取几分钟前发生的最新资讯，是其他 AI 无法比拟的优势。

**Expert 推理模式**：付费版专属的多步骤深度推理，面对复杂数学、逻辑与代码问题时表现出色。

**DeepSearch**：联网深度搜索，自动整合多个来源，给出有引用的详细报告。

**超长上下文**：Grok 4.7 支持 500K tokens 上下文窗口，处理超长文档毫无压力。

**Grok Build**：面向开发者的编程助手，Premium 及以上可访问更强大的工具集；The X Subscription 同时捆绑 Cursor 编程工具。

**风格独特**：回答风格幽默大胆，创意类任务体验好。

## 常见问题

**Q：一定要有 X 账号才能用 Grok 吗？**  
不需要。grok.com 支持独立账号注册，用邮箱即可直接使用，无需绑定 X。

**Q：提示无法访问怎么办？**  
切换网络节点到美国后重试，部分地区访问受限。

**Q：免费版每天能发多少消息？**  
免费版按滚动窗口限制，通常每2小时约10条消息。

**Q：免费版还能生成图片吗？**  
不能。图像生成对免费用户已关闭。需升级至 Plus（$8/月）可使用基础版 Imagine；Premium（$30/月）起可使用完整版图像生成和视频生成。

**Q：The X Subscription 和旧 SuperGrok 有什么关系？**  
2026年10月12日起，SpaceXAI 不再向新用户单独销售 SuperGrok。The X Subscription 将 Grok、Cursor 和 X Premium 打包，Premium（$30/月）相当于旧 SuperGrok + Cursor Pro + X Premium+ 的合集，且比三者分开购买便宜约 $60。已有旧套餐的用户可继续保留。

**Q：The X Subscription 怎么开通最方便？**  
使用激活码是最简单的方式，无需绑定信用卡，即买即用。
