⚙ GitHub 连接设置

通过 GitHub API 直接读写博客仓库。强烈建议使用 Fine-grained token，只授权这一个仓库的 Contents 读写权限，并设置过期时间（比如90天），而不是能访问你全部仓库的经典 Token。

GitHub → Settings → Developer settings → Fine-grained tokens → 选择仓库 → Contents: Read and write。用完请设过期时间，别用永久有效的。
在这台设备记住 Token（关闭浏览器后仍保留）
不勾选：Token 只保留在当前标签页，关闭浏览器/标签页就清除，更安全。仅在你自己的电脑上才建议勾选。
