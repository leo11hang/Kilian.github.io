Chrome 插件压缩包上传目录

将插件压缩包上传到本目录。软件下载页展开「Chrome 插件」卡片时，会自动列出支持的压缩包，并按实际格式显示下载按钮。

支持格式：.zip、.rar、.7z、.tar、.tar.gz、.tgz、.tar.bz2、.tbz、.tbz2、.tar.xz、.txz、.tar.zst、.tzst

建议文件名：插件英文短名-v版本号.压缩格式（扩展名建议使用小写）
例如：my-helper-v1.2.0.zip、my-helper-v1.2.0.rar、my-helper-v1.2.0.tar.gz

用户点击下载会取得仓库中原格式的文件，不会自动转换或安装。RAR、7Z 及 TAR 系列文件需要使用支持对应格式的解压工具。

解压后的插件目录应直接包含 manifest.json。用户在 Chrome 扩展程序页面开启「开发者模式」，再选择「加载已解压的扩展程序」并指向该目录。

网站仅提供文件下载与手动加载说明，不会自动安装浏览器扩展。
