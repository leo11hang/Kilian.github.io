# Platform logo assets

The download button icons in this folder are served locally by `assets/js/download-option-platforms.js`.

| File | Use and source |
| --- | --- |
| `windows.png` | Cropped Windows panes from Microsoft's Windows 11 press material: https://news.microsoft.com/june-24-2021/ |
| `macos.svg` | Apple symbol from Apple's global navigation asset: https://www.apple.com/ac/globalnav/4/en_US/images/globalnav/apple/image_large.svg . Its view box was tightened and the white fill changed to dark gray so the complete mark is visible on this site's light buttons. |
| `linux.svg` | Tux, the Linux mascot, from Wikimedia Commons: https://commons.wikimedia.org/wiki/File:Tux.svg . Attribution: Larry Ewing and The GIMP; Simon Budig; Garrett LeSage (CC0). The Commons file page includes the source and reuse notes. |

Linux does not have a single official distribution-independent product logo; this uses the widely recognized Tux mascot.
