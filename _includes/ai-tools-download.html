Windows 命令行安装教程
方式一：WinGet 安装

适合可以访问 Microsoft Store 源、但希望通过命令安装的情况。用 PowerShell 运行：

winget install --id 9PLM9XGG6VKS -s msstore
方式二：官方 MSIX 离线部署

如果设备无法访问 Store 源，可下载匹配架构的官方安装包和许可证文件：

Windows x64 MSIX Windows ARM64 MSIX 官方许可证 XML
  1. 下载一个对应架构的 MSIX 和许可证 XML，放在同一文件夹。
  2. 将它们分别重命名为 ChatGPT.msix 和 ChatGPT-License.xml。
  3. 在该文件夹打开“以管理员身份运行”的 PowerShell，执行：
Add-AppxProvisionedPackage -Online `
  -PackagePath .\ChatGPT.msix `
  -LicensePath .\ChatGPT-License.xml `
  -Regions all

离线部署需要管理员权限；安装包为 OpenAI 官方 Store 签名版本，应用使用时仍需联网。OpenAI 暂未提供独立 MSI 或非 Store EXE 安装包。macOS 提供官方 DMG 直链。
